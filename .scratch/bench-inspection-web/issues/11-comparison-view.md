# 11: 对比视图（自动配对，重构）

**What to build:** 在同一 Model 下勾选 2 个以上 Deployment，系统按 `workload_id + (mode, level)` 自动对齐各 Deployment 的 Cell，展示指标表与叠加曲线。这是 v1 的核心价值。

**Blocked by:** 06, 10

**Status:** open

- [ ] 从 Model 详情页勾选多个 Deployment **直接进入**对比视图——无需选择任何执行记录（Cell 就是当前状态）
- [ ] 按 (Workload, mode) 分节：自动对齐 `(mode, level)` 相同的 Cell，**只比交集**
- [ ] 某 Deployment 缺某个点 → 显示"未测"；两个 Deployment 没有共同点 → 明确说明，不显示空白或误导性并排
- [ ] 指标表（各 Deployment 并排）+ 叠加曲线（每条线一个 Deployment）来自**同一次接口返回**——两次请求就有两次不一致的机会
- [ ] 每个点标注各自的执行时间（读时拼装的缓解，ADR-0001）
- [ ] 不提供跨 Model 的并排视图

## 沿用自 Run 实现的教训

- **颜色是身份，不是判断**：序列色板避开绿/红配对——按数字好看程度上色，等于图表替读者做了他要自己做的判断。
- 只比交集（原实现里是"档位选择器只列出所有部署都达到的档位"）：提供没有交集的档位会得到一张只有一行的"对比"表，那不是对比，而且看起来像对比。
