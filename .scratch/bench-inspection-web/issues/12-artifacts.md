# 12: Cell 原始产物落盘与下载（重构）

**What to build:** 每个 Cell 产出一个自包含的产物目录，重跑覆盖；页面上可下载。

**Blocked by:** 04

**Status:** open

- [ ] 每 Cell 一个目录 `artifacts/cells/<cell_id>/`：`plan.json`（执行前冻结的配置，取消的 Cell 也留得下）、`level.jsonl`（逐请求计时与 token 数）、`manifest.json`（结果摘要）、`executor.log`
- [ ] **重跑时旧产物随结果一起被覆盖**（ADR-0001：无历史）
- [ ] 产物**足以在负载发生器口径被修正后重算指标**——这是自研路线唯一的"后悔药"
- [ ] 页面提供下载；产物中**不含任何密钥**（只存环境变量名，请求体不落盘）

## 沿用自 Run 实现的教训

- **不存库的是逐请求明细，落盘的是产物**：聚合值无法支撑口径修正后的重算，所以逐请求 JSONL 必须落盘。
- **落盘用"先写临时文件再改名"**：读到写了一半的文件的人，宁可看到上一版也不愿看到截断的一版。
- **`artifact_dir` 存在库里，但库里的路径只是一个值**：下载接口必须把它解析后与 artifacts 根目录比对，越界则报错。
